# Programming 5

This repository contains my individual project for the **Programming 5** course (University of Pécs, Faculty of Engineering and Information Technology).

| Folder | Contents |
| --- | --- |
| [`project/`](project/README.md) | **TradeArena**: a realtime multiplayer stock trading game built with C#/.NET microservices, RabbitMQ and SignalR, with its documentation in [`project/docs`](project/docs/README.md) |

Quick start:

```bash
cd project
docker compose up --build
```

Then open <http://localhost:8080>.
